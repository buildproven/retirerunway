Retirement planning you can check.

RetireRunway is a free Claude plugin for planning a US retirement. A tested engine does the maths. Claude explains the results, and every number points back to the exact calculation that produced it.

Open source under MIT, no paid tier. Educational, not financial advice.

Every number has a receipt

Ask a chatbot about your retirement and it will happily do the arithmetic in its head. RetireRunway doesn't let it. Claude calls the engine, the engine returns figures with a stamp, and Claude quotes the stamp.

The model never does maths
Every calculation lives in a deterministic engine with no AI in it. Claude's job is to explain what came back.
Same inputs, same answer
The Monte Carlo is seeded, nothing reads the clock, and the date is an input. The stamp's input and output hashes let you prove two runs match.
Tested on values, not shapes
The tests check the numbers themselves, and every requirement maps to the code and tests that cover it. The build fails on anything unmapped.
Your rules, your trades
You set a target mix, a cash buffer and a sell schedule. It tells you what's due and what it costs in tax. You place every order yourself.

What it models

The awkward parts of retiring before 65 in the US, all in today's dollars, out to age 95 by default.

Accounts
Taxable, 401(k), IRA, Roth, HSA and deferred comp kept apart, with the 10% penalty before 59½, the Rule of 55 and required minimum distributions.
Social Security
Both spouses, any claiming age from 62 to 70, spousal and survivor benefits, and an optional cut in line with the Trustees Report.
Health and tax
Insurance before Medicare, the ACA credit and its cliff, Medicare IRMAA, federal brackets and your state rate.
Markets
Long-run returns, 10-year forecast returns, and a replay through every start year since 1928, with 1929, 1966, 2000 and 2008 by name.
Choices
Downsizing, retiring later, side income, a job gap, Roth conversions and how much you can safely spend, side by side on the same seed.
Your accounts
Positions CSVs from Fidelity, Schwab and Vanguard, with account numbers removed before anything is saved.

Run it

On your own computer with Claude Code. You need Node 24. 

git clone https://github.com/buildproven/retirerunway
cd retirerunway
npm ci
claude mcp add --transport stdio --scope user retire-runway \
  -- npm --prefix "$PWD" run --silent mcp
mkdir -p ~/.claude/skills && cp -R skills/retire-runway ~/.claude/skills/

Then ask Claude: "Set up my retirement plan." It asks for your figures, saves them, and runs the first check.

Want it in claude.ai and on your phone? Host your own copy: it serves one owner and keeps your data in a private GitHub repo. The README has the steps.

Privacy

Run on your computer, your data stays in a folder on your computer (~/.retire-runway). A hosted copy keeps it in a private GitHub repo you own, and only your GitHub account can sign in. Account numbers are stripped from imports before anything is saved.

Your questions go to Claude under your own Anthropic account. This site has no tracking, no cookies and no sign-up.
